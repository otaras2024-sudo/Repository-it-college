# Звіт до роботи

## Тема: Вступні заняття: налаштування середовища, початок роботи з Python та Markdown.

### Мета роботи:

Налаштувати середовище роботи у VS Code, створити та налаштувати інтеграцію з GitHub, написати першу програму на Python, ознайомитися з Python Notebook та створити звіт із використанням форматування Markdown.

---

### Виконання роботи

1. Встановили та перевірили необхідні розширення VS Code:
   - Python;
   - Jupyter;
   - GitHub Copilot.

2. Створили в репозиторії папку `1_python_program` для виконання роботи.

3. Створили файл `my_first_app.py` та написали першу програму на Python.

4. У програмі використали модуль `datetime`, змінні `name` та `location`.

5. Запустили програму та отримали результат:

```text
Олександр start programming at [дата та час]. Львів is the best city!
```

6. Створили Python Notebook `my_first_app.ipynb`.

7. Виконали програму в Notebook та отримали результат її роботи.

8. Створили Markdown-комірку із заголовком:

# Моя перша програма

9. Додали до Notebook відповідь AI із прикладом простої програми:

```python
name = "Олександр"
print(f"Привіт, {name}!")
```

Програма успішно виконується та виводить привітання з іменем користувача.

10. Створили звіт роботи у файлі `README.md`.

11. Зміни були зафіксовані за допомогою Git та завантажені до GitHub.

### Результати

У результаті роботи було створено:

- `my_first_app.py` — програма на Python;
- `my_first_app.ipynb` — Python Notebook із виконаними комірками;
- `README.md` — звіт до роботи.

Репозиторій з виконаною роботою:
