# Практична робота: Перша програма на Python

## Мета роботи

Налаштувати середовище VS Code, створити та запустити першу програму на Python, а також ознайомитися з Python Notebook і Markdown.

## Виконання роботи

### 1. Перша програма на Python

Було створено файл `my_first_app.py`.

Програма використовує модуль `datetime`, виводить ім'я користувача, поточну дату та час, а також назву міста.

Результат виконання:

```text
Олександр start programming at [дата та час]. Львів is the best city!
```

### 2. Python Notebook

Було створено файл `my_first_app.ipynb`.

У Notebook виконано програму та створено Markdown-комірку із заголовком **«Моя перша програма»**.

### 3. Програма від AI

AI запропонував просту програму для виведення привітання користувачу:

```python
name = "Олександр"
print(f"Привіт, {name}!")
```

Програма успішно виконується та виводить привітання з іменем користувача.

## Висновок

Під час роботи було налаштовано середовище VS Code, створено та запущено програму на Python, виконано код у Python Notebook та використано форматування Markdown.
